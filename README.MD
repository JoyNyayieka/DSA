This is a repository covering some of the key data structures and algorithms.   

The topics covered include:

1. Algorithmic Notation and Search Algorithms
2. Sorting Algorithms and Recursion
3. Basic Data Structures (Arrays and Hashmaps)
4. Linear Data Structures (Linked Lists, Stacks, and Queues)
5. Intro to Divide & Conquer Algorithms (Greedy & Dynamic Programming)
6. 0-1 & Unbounded Knapsack Dynamic Programming (NP-Complete Problems)
7. Multidimensional Dynamic Programming (LCS & DP in Grid)
8. Trees and Tree-based Algorithms
9. Graphs and Graph Traversal Algorithms
10. Backtracking and Pathfinding Algorithms
